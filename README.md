# Internet Speed Test (URL)

Небольшая CLI-утилита на Python для оценки скорости скачивания с конкретного HTTP(S)-ресурса. Она **последовательно** выполняет 10 запросов к одному URL, полностью дочитывает тело каждого ответа и выводит объём данных, время запросов и среднюю скорость.

> Это замер скорости получения файла с выбранного сервера, а не универсальная диагностика интернет-канала. Результат зависит от сервера, маршрута, размера файла, TLS/HTTP накладных расходов, кэширования и текущей нагрузки.

## Возможности

- Ровно 10 последовательных запросов (следующий начинается только после полного ответа предыдущего).
- Потоковое чтение блоками по 64 KiB: содержимое файла не загружается целиком в память и не сохраняется на диск.
- Время каждого запроса, среднее арифметическое, суммарный объём и расчётная средняя скорость.
- Стандартная библиотека Python — устанавливать сторонние пакеты не нужно.
- Проверка URL и тайм-аута; понятные ошибки при проблемах соединения и HTTP.

## Требования

- Python 3.10 или новее.
- Доступ к интернету и URL, который отдаёт тело ответа по HTTP или HTTPS.

## Быстрый старт

```bash
python3 speed_test.py "https://example.com/large-image.jpg"
```

Тайм-аут на каждый запрос можно изменить (значение по умолчанию — 60 секунд):

```bash
python3 speed_test.py "https://example.com/large-image.jpg" --timeout 120
```

Справка:

```bash
python3 speed_test.py --help
```

## Пример вывода

```text

Запрос 01/10: 2.40 MB за 0.812 с
Запрос 02/10: 2.40 MB за 0.795 с
...

Результат
Среднее время запроса:       0.804 с
Всего скачано:               24.00 MB (24,000,000 байт)
Суммарное время скачивания:  8.040 с

```

Цифры выше приведены только для иллюстрации.

## Единицы измерения и формулы

Используются **десятичные** единицы: `1 kB = 1 000 байт`, `1 MB = 1 000 000 байт`, `1 GB = 1 000 000 000 байт`. Итог также содержит точное количество байт.

- `среднее время запроса = сумма длительностей 10 запросов / 10`;
- `MB/s = сумма скачанных байт / сумма длительностей / 1 000 000`;
- `Мбит/с = MB/s × 8`.

Суммарная длительность складывает время выполнения запросов; поскольку они идут последовательно, параллельной загрузки и её влияния на измерение нет. Время установления соединения и получения ответа включено в длительность.

## Тесты

Тесты написаны на встроенном `unittest`; сетевой доступ для них не нужен:

```bash
python3 -m unittest discover -s tests -v
```

Также можно проверить CLI и синтаксис:

```bash
python3 -m py_compile speed_test.py
python3 speed_test.py --help
```

## Замечания

- По умолчанию тайм-аут составляет 60 секунд **на каждый запрос**, а не на весь запуск.
- Ответы HTTP вне успешного диапазона обрабатываются как ошибка; при ошибке выполнение завершается с ненулевым кодом.
- Повторное скачивание одного файла может попасть в кэш сервера или промежуточной сети. Для более показательного замера выбирайте достаточно большой, стабильно доступный файл и проверяйте, что URL разрешает повторные загрузки.
- Не запускайте замер на URL, для которого повторные запросы нежелательны или создают заметную нагрузку.
